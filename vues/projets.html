Réseau virtuel sous VirtualBox

Projet encadré (PPE) — Lycée Paul Louis Courrier

VirtualBox Windows Server Linux
🎯 Objectif

Mettre en place un réseau virtuel complet avec un serveur Windows (Active Directory, DHCP) et une machine cliente Linux, pour simuler un environnement d'entreprise.

🔧 Technologies utilisées

VirtualBox, Windows Server 2019, Ubuntu, Active Directory, DHCP.

👤 Mon rôle

Conception et déploiement complet de l'infrastructure — installation des VMs, configuration réseau, création des utilisateurs AD.

⚠️ Difficultés & solutions

Problème de résolution DNS entre la machine cliente et le serveur — résolu en renseignant manuellement l'IP du serveur comme DNS préféré dans les propriétés réseau de la VM cliente.

Infrastructure Active Directory & Haute Disponibilité (sio.local)

Travaux Pratiques (2e année) — ISCB · BTS SIO SISR

Active Directory GPO DFS-N / DFS-R IIS / HTTPS / NLB
🎯 Objectif

Déployer une infrastructure d'entreprise complète sous Windows Server (domaine sio.local) avec redondance des services critiques (AD, DNS, DHCP), administration centralisée par GPO, partages répliqués sous DFS et hébergement intranet sécurisé en haute disponibilité[cite: 1, 2, 3, 4].

🔧 Technologies utilisées

Windows Server (DC1 / DC2), AD DS, DNS, DHCP Failover, GPMC (modèles ADMX, déploiement MSI), NTFS / ABE, DFS-N & DFS-R, IIS 10, certificats TLS / HSTS, cluster NLB, PowerShell[cite: 1, 2, 3, 4].

👤 Mon rôle

Installation et promotion des deux contrôleurs de domaine, configuration du basculement DHCP (50/50), création des stratégies de sécurité et de personnalisation (SISR/SLAM), mise en place des espaces de noms DFS et sécurisation HTTPS[cite: 1, 2, 3, 4].

⚠️ Difficultés & solutions

Prévention des conflits de SID lors du clonage de DC2 (résolu via Sysprep), gestion de l'ordre d'application des GPO (LSDOU) et des accès NTFS/ABE, ainsi que le mode multidiffusion NLB pour préserver la réplication entre contrôleurs[cite: 1, 2, 3, 4].
